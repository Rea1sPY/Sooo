# یک دقیقه تا مرگ — ONE MINUTE TO DIE
بازی ترسناک دوبعدی اندروید با **Godot 4.2 (GDScript)** — کاملاً آفلاین، بدون هیچ فایل بیرونی (گرافیک و صدا هنگام اجرا با کد ساخته می‌شوند).
**ساخته‌شده توسط ReaLsPY · پشتیبانی: t.me/MateoHastam**

## داستان
در یک مرکز تحقیقاتی متروکه بیدار می‌شوی. چراغ‌ها خاموش، درها قفل و موجودی ناشناس در ساختمان در حرکت است. شمارش معکوس ۶۰ ثانیه شروع می‌شود. با تمام شدن زمان یا گرفتار شدن، حلقه از نو شروع می‌شود؛ اما یادداشت‌ها و رمزهایی که پیدا کرده‌ای می‌مانند و **دشمن از رفتار تو یاد می‌گیرد**.

## امکانات
- **صفحه‌ی بارگذاری سینمایی** (`scripts/loading.gd`): لوگوی گلیچی با جدایش رنگی، اسکن‌لاین و غبار و دانه‌ی فیلم، گزارش زنده‌ی راه‌اندازی (`boot::core … OK`)، هفت مرحله‌ی بارگذاری با نوار پیشرفت قطعه‌قطعه و درصد فارسی، نکته‌های چرخشی، نشانگر REC، گوشه‌های قاب، دکمه‌ی رد کردن و ورود با لمس/کلید؛ بعد از آن محو شدن نرم به منو
- حلقه‌ی دقیقاً ۶۰ ثانیه‌ای با تایمر همیشه‌پیدا؛ نزدیک پایان: ضربان قلب، آلارم، لرزش دوربین، سوسو زدن نور، قرمز شدن حاشیه، موسیقی اضطراب‌آورتر
- ۸ بخش ساختمان: اتاق شروع، راهروهای تاریک، آزمایشگاه، اتاق برق، انبار، اتاق نگهبانی، اتاق امنیت، خروج اضطراری (+ آرشیو). دیوار و در با برخورد واقعی
- **نورپردازی پویا و سایه**: چراغ‌قوه‌ی مخروطی با باتری، سایه‌ی دیوارها، چراغ‌های اضطراری بعد از وصل شدن برق
- کنترل لمسی چندانگشتی: جوی‌استیک شناور، تعامل، دویدن، چراغ‌قوه، دفترچه، توقف
- **هوش مصنوعی دشمن** (`scripts/enemy.gd`): گشت، شنیدن صدای دویدن/درها/اشتباه معماها، دیدن (مخروط دید + خط دید با Raycast)، تعقیب، جست‌وجوی آخرین محل دیده‌شدن، وارسی کمدها
- **یادگیری بین حلقه‌ها** (`Global.memory`، ذخیره‌ی دائمی): مسیرهای فرار، کمدهایی که زیاد استفاده کنی و محل مرگ‌ها وزن می‌گیرند؛ دشمن در حلقه‌های بعد آن‌جاها را بیشتر گشت می‌زند و کمدهای محبوبت را زودتر باز می‌کند. با هر حلقه کمی فراموش هم می‌کند
- ۷ آیتم/سند: کارت دسترسی، کلید، فیوز، چراغ‌قوه، ۷ یادداشت مخفی، ۳ سند محرمانه، رمز امنیتی
- ۳ معمای ضروری: **قفل رمزی ۴ رقمی** (رمز از ۳ یادداشت جمع می‌شود)، **ترتیب دسته‌های برق** (به‌اضافه‌ی فیوز)، **اتصال سیم‌های هسته**. اشتباه کردن سروصدا دارد و دشمن را می‌کشاند
- **۴ پایان**: فرار، حقیقت (با ۳ سند)، پایان چرخه (خاموش کردن هسته)، پایان مخفی (بعد از خواندن هر ۷ یادداشت)
- ذخیره‌ی دائمی: یادداشت‌ها، رمزها، تعداد مرگ‌ها، بهترین زمان، پایان‌های باز‌شده، حافظه‌ی دشمن، تنظیمات
- منو: شروع بازی، ادامه بازی، دفترچه‌ی سرنخ‌ها، تنظیمات، راهنما. **سه سطح سختی: آسان / متوسط / سخت**
- تنظیمات: صدای موسیقی و جلوه‌ها (و قطع هرکدام)، حساسیت جوی‌استیک، اندازه‌ی دکمه‌ها، لرزش، روشنایی، لرزش دوربین، افکت‌های تصویری، سختی؛ **پایین تنظیمات: دکمه‌ی «پشتیبانی» که مستقیم تلگرام را باز می‌کند** و نام سازنده
- توقف خودکار و ذخیره وقتی اپ به پس‌زمینه می‌رود؛ دکمه‌ی بازگشت اندروید پنجره‌ی توقف را باز می‌کند
- تمام گرافیک (کشیده با کد) و صدا (سنتز در لحظه) داخل خود بازی است؛ شبکه استفاده نمی‌شود

## گرفتن APK با GitHub (بدون نصب چیزی)
۱. مخزن GitHub بسازید و **محتوای این پوشه** را آپلود کنید. اگر آپلود پوشه خطا داد، پوشه‌ها را جدا جدا بفرستید (`scripts`، `scenes`، `tools`، `fonts`) و فایل‌های `project.godot`، `export_presets.cfg`، `icon.svg`، `.gitignore` را هم.
۲. فایل workflow را داخل خود GitHub بسازید: **Add file ▸ Create new file** ▸ اسم دقیقاً `.github/workflows/build-apk.yml` (اول نقطه) ▸ متن فایل همین پروژه را paste کنید ▸ **Commit changes**.
۳. تب **Actions** ▸ اجرای «Build Android APK (Godot)» (یا Run workflow). ۵ تا ۱۵ دقیقه صبر کنید.
۴. بعد از تیک سبز، پایین صفحه‌ی اجرا در **Artifacts** فایل `one-minute-to-die-apk` را دانلود کنید؛ داخل ZIP فایل `OneMinuteToDie.apk` است (مسیر روی Runner: `build/android/OneMinuteToDie.apk`).
۵. APK را روی گوشی نصب کنید (اجازه‌ی «نصب از این منبع»، اگر Play Protect هشدار داد Install anyway).
اگر مرحله‌ی «Export debug APK» قرمز شد، چند خط آخر خطا را برای سازنده بفرستید.

## ساخت APK با Godot روی ویندوز (راه دوم)
۱. Godot **4.2.2 (Standard)** و Export Templates (منوی Editor ▸ Manage Export Templates ▸ Download and Install) را نصب کنید.
۲. JDK 17 و Android SDK (Command-line Tools؛ Platform 34 و Build-Tools 34.0.0) را نصب کنید. برای کلید debug: `keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android -keystore debug.keystore -storepass android -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12`
۳. Editor ▸ Editor Settings ▸ Export ▸ Android: مسیر Java SDK، Android SDK و debug keystore (کاربر `androiddebugkey`، رمز `android`) را بدهید.
۴. پروژه را باز کنید ▸ Project ▸ Export ▸ Android ▸ **Export Project** (تیک Export With Debug) ▸ APK.

## فونت
فونت فارسی همراه پروژه است: `fonts/Vazirmatn-Regular.ttf` (مجوز OFL در `fonts/OFL.txt`). همه‌ی متن‌ها با همین فونت رسم می‌شوند و بازی دیگر به فونت سیستمِ دستگاه وابسته نیست — همین وابستگی باعث می‌شد APK روی گوشی فقط صفحه‌ی سیاه نشان بدهد. اگر فونت دیگری می‌خواهید، با نام `fonts/horror.ttf` بگذارید تا اول از همه استفاده شود (باید حروف فارسی داشته باشد).

## افزودن محتوا
همه‌ی محتوا در `scripts/data.gd` است: اتاق‌ها، درها، مبلمان، پیکاپ‌ها، یادداشت‌ها، متن پایان‌ها و پارامترهای سختی. بعد از ویرایش `python3 tools/validate_data.py` را اجرا کنید تا مطمئن شوید هنوز قابل‌حل است و همه‌چیز در دسترس است.
